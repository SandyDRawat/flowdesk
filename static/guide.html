Phase one: Gemini rewriting

Add your Gemini API key in Settings. The key is kept in server memory until restart or disconnect. Enable AI on a task, preview its title, description and type, then send it to Gemini. Review suggestions before applying. No project files or project MCP context are sent.

Assistant → Flowdesk

The optional local MCP server lets Claude or another assistant capture work, schedule tasks, record comments and assignments, and read trackers. It shares the same local database when configured with the same database path.

Local by design

This release is for one local user. Public team hosting requires authentication and per-user isolation and is not supported yet.
