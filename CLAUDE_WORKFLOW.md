# Optional assistant workflow

Use the Flowdesk MCP tools when the user asks to track substantive work. Search for duplicates, capture useful descriptions and dates, and preserve existing notes. Start/resume timers only when work starts; pause them when work pauses. Record status updates and handoffs explicitly. Creating a task does not authorize executing it, sending messages, or publishing anything externally.

Choose an explicit workspace root and database in the MCP client configuration. See MCP.md. Do not put secrets or private transcripts into task records. The local app's Gemini feature and the assistant's own provider authentication are independent.
